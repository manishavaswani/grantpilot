GrantPilot

A grant-application cockpit for academics. Build your researcher profile once — import it from ORCID, OpenAlex, or your CV — then generate every document a funder requires (biosketches, current & pending support, letters, summaries) and track each application step by step. No account, no server — everything lives in your browser's local storage. Funder rules are transcribed from official guidelines with sources and a verification date; always re-check before submitting.

Researcher profile

Populate once, reuse everywhere — every document generator draws from this profile. All fields are editable; everything is stored only in this browser's localStorage.

Import

ORCID auto-import recommended

Pulls your public ORCID record: name, affiliations, education, employment, and works. Uses the free, CORS-enabled ORCID public API — nothing is sent anywhere else.

OpenAlex adds citation metrics (cited-by count, h-index) and your top works — by ORCID iD, or by name if no iD is set.

CV / résumé upload

Upload a PDF (parsed in-browser with pdf.js) or DOCX (mammoth.js). Text is extracted locally and heuristically mapped into profile fields — you confirm what gets merged on the next screen. Nothing is uploaded to any server.

Google Scholar — BibTeX export paste

Google Scholar blocks automatic import, so paste instead: on your Scholar profile select papers → Export → BibTeX, copy the result, and paste it here. Entries become publications in your profile.

LinkedIn paste

LinkedIn does not allow automatic profile import. On LinkedIn: your profile → More → Save to PDF, open the PDF, copy the text, and paste it here. Experience and Education sections are heuristically parsed.

ResearchGate paste

ResearchGate also blocks automated access. Copy your profile's Publications list (and Education section) as text and paste it here.

Import history

GrantPilot runs entirely in your browser. Funder requirements are transcribed from official guidelines with source URLs and a verification date in js/data/grants.js — always verify against the current solicitation before submitting; GrantPilot drafts biosketch and support-statement content, but NSF and NIH require the final certified PDFs to be generated in SciENcv. Profile import uses the public ORCID and OpenAlex APIs; LinkedIn, Google Scholar, and ResearchGate block automated import, so those are manual paste workflows. Documents are generated with docx.js, CV text extraction with pdf.js and mammoth.js (pinned CDNs).
